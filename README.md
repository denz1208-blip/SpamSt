# СЛЕЗА БЕЗДНЫ (Godot 4)

Полноценный рогалик в стиле The Binding of Isaac на движке **Godot 4.3**.

## Как скачать и запустить (одним архивом)

1. На странице репозитория GitHub нажмите зелёную кнопку **Code → Download ZIP** — скачается весь проект одним файлом.
   Либо напрямую: https://github.com/denz1208-blip/SpamSt/archive/refs/heads/main.zip
2. Распакуйте архив.
3. Скачайте Godot 4.3 (бесплатно): https://godotengine.org/download — нужна версия **4.3** (Standard, не .NET).
4. Откройте Godot → **Import** → выберите файл `project/project.godot` → **Import & Edit**.
5. Нажмите **F5** (Run Project). Игра запустится.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение |
| Стрелки | Стрельба слезами |
| E | Бомба |
| Q | Активный предмет |
| M / Esc | Пауза / карта |
| Enter | Подбор предмета, покупка |

## Что внутри

- **3 персонажа**: Иссак (баланс), Магдалина (быстрая стрельба, мало HP), Каин (дальняя атака бичом... т.е. мощные слёзы)
- **3 этажа**: Подвал → Пещеры → Глубины, генерация комнат алгоритмом BFS
- **Боссы**: Монстро, Герцог мух, Гнилой Глаз
- **Враги**: ползающие мутанты, летучие мыши, плевающие головы, пауки, мухи, скелеты
- **15+ предметов** с реальными эффектами (Серный огонь, Полифем, Серафим, Внутренний глаз и др.)
- Магазины, бомбы, открывающие тайники, монеты, пилюли
- Процедурная пиксельная графика и синтезированный звук (без внешних ассетов)
- Проверка обновлений через version.json (updater.gd)

## Обновление игры

Чтобы получить новую версию — просто снова скачайте ZIP (Code → Download ZIP) или сделайте `git pull`.
