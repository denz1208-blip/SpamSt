## ✨ Введение:
Это простой бот для массового оставления комментариев в Steam. Он отправляет комментарии с *одного или нескольких* аккаунтов (мультиаккаунты) в *множество* профилей, групп, предметов Мастерской (sharedfiles) или обсуждений.

Проект представляет собой облегчённую версию бота для Steam — для пользователей, которым нужно лишь регулярно оставлять комментарии друзьям.

> [!WARNING]
> Разработчик не несёт ответственности и не могу быть привлечён к ответственности за любые действия оператора/пользователя этого бота.
> Используя это приложение, вы соглашаетесь использовать его ответственно!

## 🖥️ Интерфейс программы:
Начиная с текущей версии, программа запускается с **удобным консольным интерфейсом (меню)**. Больше не обязательно редактировать текстовые файлы вручную — всё можно делать прямо из меню:

```
*-=-=-=-=-=-=-=-=-= МЕНЮ =-=-=-=-=-=-=-=-=-*
> 1. Написать комментарий (можно в цикле - по одному за каждый проход)
> 2. Показать список комментариев
> 3. Удалить комментарий
> 4. Очистить все комментарии
> 5. Показать / изменить настройки (задержка, повтор цикла)
> 6. Управление destinations.txt (адресаты)
> 7. Аккаунты (мультиаккаунты: добавить / удалить)
> 8. Запустить комментирование
> 9. Обновить программу с GitHub (без переустановки)
> 10. Выход
*-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-*
```

**Написание комментариев в цикле:** выберите пункт `1`, укажите количество комментариев (например, `5`) и по очереди введите каждый текст — программа сама сохранит их в `comments.txt`. Пустая строка прерывает ввод.

**Циклическое комментирование:** в пункте `5` можно настроить `loopRepeats` (сколько раз цикл проходит по всему списку адресатов) и `loopDelay` (пауза в миллисекундах между полными циклами). Бот будет писать комментарии по кругу заданное число раз.

**Обновление программы:** выберите пункт `9` в меню (или выполните команду `npm update-bot` в папке программы) — свежие файлы скачаются с GitHub и заменят старые **без переустановки**. Ваши личные файлы (`config.json`, `accounts.json`, `tokens.json`, `comments.txt`, `destinations.txt`) при этом **не трогаются**. После обновления перезапустите программу командой `npm start`.

**Как запустить комментирование:** добавьте хотя бы один аккаунт (пункт `7`), убедитесь что есть комментарии (пункт `1`) и адресаты (пункт `6`), затем выберите пункт `8`. При первом входе каждого аккаунта будет запрошен Steam Guard код (или показан QR-код, если задан `qrcode`) — после успешного входа токен сохранится, и повторный ввод не потребуется. Можно добавить несколько аккаунтов — бот будет комментировать с каждого из них параллельно.

Если вы хотите запустить бота **без интерфейса** (старое поведение — сразу логин и комментирование), используйте флаг `--no-ui`:

```
node index.js --no-ui
```

## 📝 Установка и подготовка:

### Шаг 1. Скачайте программу
Скачайте архив с исходным кодом, нажав сюда: **[Download ZIP](https://github.com/denz1208-blip/SpamSt/archive/master.zip)**
(или клонируйте репозиторий командой `git clone https://github.com/denz1208-blip/SpamSt.git`).

Распакуйте ZIP-архив и откройте папку `SpamSt`.

### Шаг 2. Установите Node.js
Для работы программы необходим **Node.js версии не ниже 16.0.0**: [Скачать Node.js](https://nodejs.org/)

Рекомендуется установить последнюю LTS-версию с официального сайта. Установщик для Windows запустится сам — просто нажимайте «Далее» до конца.

Чтобы проверить, установлен ли Node.js и какая у вас версия, введите в консоли или терминале:

```
node --version
```

Если команда не найдена — Node.js не установлен, вернитесь к началу шага 2.

### Шаг 3. Установите зависимости программы
Откройте консоль (терминал) **в папке с программой** (см. инструкцию для Windows ниже в разделе «🚀 Запуск») и выполните:

```
npm install --omit=dev
```

Дождитесь завершения установки — будут скачаны все необходимые библиотеки (появится папка `node_modules`).
Сообщения вида «x vulnerabilities» можно игнорировать — они неизбежны и не представляют для вас опасности.

## ⚙️ Настройка:

**Аккаунты и вход в Steam (`accounts.json`, пункт 7 меню):**

Начните с **пункта 7 меню — «Аккаунты»**: там можно добавить, обновить или удалить аккаунты. Программа поддерживает **мультиаккаунты** — комментарии пишутся сразу со всех добавленных аккаунтов (у каждого своя сессия и свой токен входа).

Чтобы добавить аккаунт, выберите `a` и введите:
1. **Логин Steam** (accountName) — имя вашего аккаунта;
2. **Пароль** — обычный пароль от Steam. Если хотите войти **по QR-коду** (без пароля), вместо пароля введите `qrcode` — при запуске комментирования в консоли появится QR-код, который нужно отсканировать мобильным приложением Steam;
3. **sharedSecret** (необязательно) — специальный ключ Steam Guard (из настроек мобильного приложения Steam → «Метод подтверждения», кнопка «Проверить код восстановления»). Если он указан, код Steam Guard вводиться не будет — программа генерирует его сама. Если у вас его нет — просто нажмите Enter: при первом входе программа попросит ввести одноразовый код Steam Guard из письма/приложения, а затем **сохранит токен**, и больше пароль и код вводить не потребуется.

Данные хранятся в файле `accounts.json` (создаётся автоматически). При желании его можно заполнить вручную:

```json
[
    { "accountName": "логин1", "password": "пароль1", "sharedSecret": "" },
    { "accountName": "логин2", "password": "qrcode", "sharedSecret": "" }
]
```

Старый файл `logininfo.json` (одиночный аккаунт) поддерживается обратно: если `accounts.json` ещё не создан, данные из него перенесутся автоматически. Сохранённые токены входа лежат в `tokens.json` — их никогда не нужно редактировать вручную.

&nbsp;

**Комментарии (`comments.txt`):**

Здесь хранятся тексты комментариев, которые бот выбирает случайным образом. Проще всего добавлять их через **пункт 1 меню** (в том числе сразу много — в цикле). При желании можно отредактировать файл вручную: один комментарий на каждой строке.

&nbsp;

**Адресаты (`destinations.txt`):**

Можно управлять через **пункт 6 меню**, либо открыть файл `destinations.txt` текстовым редактором.
Впишите URL-адреса, vanity-имена или steamID64 каждого профиля/группы/предмета мастерской/обсуждения, куда нужно оставить комментарий — по одному адресу на строку.

Пример:
```
ID1
steamcommunity.com/id/name2
https://steamcommunity.com/profiles/ID3
Ваш публичный адрес профиля Steam (например, имя вашего custom-URL)
https://steamcommunity.com/app/739630/discussions/0/1750150652078713439
https://steamcommunity.com/sharedfiles/filedetails/?id=2496710411
```

&nbsp;

**Конфигурация (`config.json`):**

Откройте `config.json` текстовым редактором (или меняйте значения через **пункт 5 меню** — изменения сохраняются автоматически):

```json
{
    "destinationResolveDelay": 1000,
    "commentdelay": 7500,
    "postDelay": 7500,
    "accountStartDelay": 2000,
    "playingGames": ["Idling", 440, 730],
    "afkMessage": "Hi, I'm idling.",
    "loopRepeats": 1,
    "loopDelay": 0
}
```

- `playingGames` — статус и игры, которые отображаются во время работы бота. Формат массива: `["текст кастомной игры", id игры, id игры]`.
  Оставьте массив пустым (`"playingGames": []`), если бот не должен ничего «запускать». Уберите первый аргумент и оставьте только id игр, если не хотите отображать текст «Non-Steam game» на профиле.
- `afkMessage` — автоответ, если кто-то напишет вам во время работы бота. Оставьте пустой строкой (`"afkMessage": ""`), чтобы отключить.
- `commentdelay` — базовая задержка в миллисекундах. Рекомендуется оставить значение по умолчанию: слишком низкое значение приведёт к ошибкам кулдауна, так как Steam воспримет вашу активность как спам. Если ошибки кулдауна появляются даже со значениями по умолчанию — увеличьте этот параметр.
- `postDelay` — задержка **между отдельными постами одного аккаунта** в миллисекундах (по умолчанию равна `commentdelay`). Именно её стоит увеличивать, если Steam отвечает отказом на частые посты.
- `accountStartDelay` — пауза в миллисекундах между стартами аккаунтов при мультиаккаунтах (по умолчанию 2000). Аккаунты запускаются последовательно, каждый со своей паузой `postDelay` между постами.
- `loopRepeats` — сколько раз цикл комментирования проходит по всему списку адресатов (по умолчанию 1).
- `loopDelay` — пауза в миллисекундах между полными циклами (не может быть меньше `commentdelay`).
- `destinationResolveDelay` — задержка между преобразованием каждого адреса в ID. Значения по умолчанию (1000 мс) достаточно; увеличивать нужно только при очень большом количестве адресатов или при ошибках на старте.

Если возникают проблемы — смотрите раздел *💡 Устранение неполадок* ниже.

## 🚀 Запуск программы:
Откройте консоль (терминал) **в папке с программой** и выполните:

```
node index.js
```

или эквивалентную команду:

```
npm start
```

Программа покажет меню интерфейса:

1. **Добавьте аккаунт Steam через пункт `7` → `a`** (логин, пароль или `qrcode`; при желании — sharedSecret). Можно добавить несколько аккаунтов — комментарии пойдут сразу со всех.
2. Добавьте комментарии через пункт `1` (можно сразу несколько — в цикле).
3. Проверьте/добавьте адресатов через пункт `6`.
4. При необходимости настройте задержки и повторы через пункт `5`.
5. Нажмите `8`, чтобы запустить комментирование.

При первом входе каждого аккаунта бот запросит код Steam Guard (или покажет QR-код для сканирования приложением Steam), после чего сохранит токен — дальше вход будет автоматическим, без пароля и кода. Бот начнёт оставлять комментарии по каждому адресу из списка — один за другим, с заданной задержкой. После завершения можно вернуться в меню и запустить цикл снова.

Чтобы запустить бота **без меню** (сразу комментирование, как в старых версиях):

```
node index.js --no-ui
```

**Как открыть консоль в нужной папке на Windows:**
- Откройте папку с ботом через Проводник

На macOS/Linux: откройте Терминал и перейдите в папку командой `cd /путь/к/SpamSt`.

## 💡 Устранение неполадок:
Если вы нарушите синтаксис конфигурационных файлов (из руководства по настройке выше), программа выдаст ошибку, так как не сможет прочитать файл. При ошибке синтаксиса проверьте частые причины:
- забыли запятую в конце строки?
- в самой последней строке запятой быть не должно (смотрите пример выше)
- забыли кавычки `"` при вводе текста?

Если `node index.js` пишет, что команды `node` нет — не установлен Node.js (см. Шаг 2).
Если модули не находятся — вы пропустили установку зависимостей: выполните `npm install --omit=dev` в папке программы.

### Steam отказал в публикации: "The settings on this account do not allow you to add comments."
Эту ошибку выдаёт сам Steam — программа тут ни при чём (именно поэтому раньше казалось, что «пишет, что написал», а комментария нет: теперь статус считается только по реальному ответу Steam). Возможные причины:
- **Группа закрыта или требует участия** — чтобы писать на стене группы, аккаунт должен быть её участником. Вступите в группу этим аккаунтом (кнопка «Присоединиться») и повторите.
- **Комментарии в группе отключены** администраторами — тогда писать туда невозможно в принципе.
- **Ограничения самого аккаунта Steam**: новый аккаунт без покупки в Steam (ограниченный уровень), семейный/родительский режим, недавняя смена e-mail/пароля, либо временный бан на комментарии за спам. Проверьте, можете ли вы вручную написать комментарий на стену этой группы с этого аккаунта через браузер.
- Для профилей аналогично: у владельца могут быть закрыты комментарии, либо аккаунт в вашем списке игнорирования.

### Ошибка "getIDTypeAndID is not a function" при загрузке адресатов
Это значит, что на вашем компьютере всё ещё лежит СТАРАЯ версия программы. Выполните `npm update-bot` (или скачайте ZIP заново) и перезапустите.

При других ошибках или вопросах, пожалуйста, [создайте issue здесь](https://github.com/denz1208-blip/SpamSt/issues/new).
Всё, что появляется в окне консоли/терминала, также сохраняется в файл `output.txt`. Приложите содержимое последнего запуска к вашему issue — так мне будет проще помочь вам разобраться.
