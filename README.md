# 💧 СЛЕЗА ПОДЗЕМЕЛЬЯ (The Underground Tear)

Рогалик (roguelike) в духе **The Binding of Isaac**, написанный на чистом
**HTML5 Canvas + JavaScript** — без сборщиков, без зависимостей, без интернета
(кроме функции автообновления). Просто открой `index.html` в браузере и играй.

---

## 🚀 Как запустить

**Способ 1 — самый простой:**
двойной клик по файлу `index.html` (игра работает прямо с диска, `file://`).

**Способ 2 — через локальный сервер (рекомендуется для автообновления):**

```bash
# Python
python3 -m http.server 8000
# или Node
npx serve .
```

Затем открой в браузере: <http://localhost:8000>

> ⚠️ Функция «Проверить обновление» требует запуска через HTTP(S) — при открытии
> как файл браузер может блокировать fetch-запросы. Сама игра при этом работает.

🎮 **Онлайн-версия (GitHub Pages):** включи в репозитории
`Settings → Pages → Branch: main` — и игра будет доступна по адресу
`https://denz1208-blip.github.io/SpamSt/`.

## 🕹️ Управление

| Клавиши | Действие |
|---|---|
| **W A S D** | Движение персонажа |
| **Стрелки ← ↑ ↓ →** | Стрельба слезами в 4 направлениях |
| **E** | Подобрать предмет / купить в магазине |
| **Q** | Поставить бомбу (взрыв: урон врагам, сносит камни и двери) |
| **SPACE** | Активный предмет «Извержение слёз» (когда получен и заряжен) |
| **ESC** | Показать/скрыть карту этажа |

## 🏰 Структура забега

Три этажа, каждый генерируется случайно:

1. **Подвал** → босс *Гнойный Гузеник*
2. **Катакомбы** → босс *Мимоза, Жужжащий Бог*
3. **Чрево** → финальный босс *Чревoход*

Цвета комнат на карте (ESC):
🟢 старт · ⬜ обычная (бои) · 🟡 **сокровищница** (бесплатный предмет!) ·
🔵 **магазин** (покупки за монеты) · 🔴 **босс** · 🟣 **тайная комната**
(вход — взорвать бомбой стену рядом с ней).

После зачистки комнаты открываются двери; из врагов выпадают сердца 💗,
монеты 🪙, ключи 🗝️ и бомбы 💣. В обычных комнатах иногда после боя появляется
предмет — бери клавишей **E**.

## ⚔️ Враги и боссы

**Мелочь:** мухи (кружат), атак-мухи (пикут), пауки (прыжками), гапёры (идут в лоб),
стрелки и плевуньи (плюются), тараны (разгоняются), сгустки (медленные, жирные).

**Боссы** имеют несколько фаз атак: рывки, круговые залпы, спавн миньонов.
Совет: держи дистанцию и стреляй «на отходе» — во время удара ты неуязвим 1 секунду.

## 🎁 Предметы (12 пассивок + 1 активный)

Сердце слезотворца (+1 контейнер), Кровавая шиповница (+урон), Ртутная капля
(скорострельность), Долгий вздох (дальность), Расколотое горе / Тройная печаль
(+слезы веером), Тупая игла (большие слёзы), Сестринский долг, Счастливое зерно
(удача), **Желечная желчь** (пробитие врагов насквозь), **Тлеющий уголёк**
(поджог), **Взвешенное сердце** (самонаведение слёз).

Активный предмет **«Извержение слёз»** даётся за победу над первым боссом:
SPACE = неуязвимость + залп во все стороны, долгая перезарядка.

Предметы складываются — собирай билды: например, *пробитие + самонаведение +
веер* превращает тебя в мясорубку.

## 🔄 Обновление игры через GitHub

Игра умеет обновляться сама, прямо из браузера:

1. В меню есть кнопка **«🔄 ПРОВЕРИТЬ ОБНОВЛЕНИЕ»**, плюс автопроверка при запуске
   (плашка в правом верхнем углу).
2. Игрок нажимает «Обновить» — свежие файлы (`js/*.js`) скачиваются с
   `raw.githubusercontent.com/denz1208-blip/SpamSt/main` и кладутся в localStorage.
3. При следующем запуске игра автоматически подменяет код на обновлённый
   (без перезагрузки файлов на диске). Кнопка «Сбросить кэш» возвращает локальную версию.

### Как выпустить обновление (для автора)

1. Отредактируй код игры.
2. Подними версию в **двух местах**: `version.json` (поле `"version"`, например
   `1.0.0 → 1.1.0`, и опиши изменения в `"notes"`).
3. Запушь в ветку `main`:

```bash
git add -A && git commit -m "v1.1.0: описание" && git push origin main
```

Все игроки, у которых стоит старая версия, увидят предложение обновиться.

## 💀 Советы новичку

- Не стой в центре комнаты — кружи вокруг камней.
- Шипы наносят полсердца, ямы непроходимы (перелетай через них нельзя — обходи).
- Тайные комнаты искомые бомбами — всегда носи 1–2 запасные.
- Монеты копи для магазина: предметы там стоят 3–5 монет.
- Победа над боссом открывает люк на следующий этаж. Удачи, плакса. 🩸
